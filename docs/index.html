Документация по проекту «Mesto»

Кратко: статический веб-сайт, запуск и деплой через npm/webpack/gh-pages. Хостинг — GitHub Pages.

1. Что это

Простой клиентский сайт (HTML/CSS/JS). Исходники находятся в папке src/. Сборка выполняется Webpack, результат — в dist/. Для публикации используется пакет gh-pages.

2. Требования

  • Node.js (v16+ рекомендуется)
  • npm
  • Доступ к репозиторию на GitHub для публикации Pages

3. Структура (ключевые файлы)

mesto-main/
  src/
    index.html
    index.js
    pages/
      index.css
    vendor/
      fonts/
        Inter-*.woff2
      fonts.css
      normalize.css
  package.json
  webpack.config.js
  README.md

4. Быстрый запуск локально

  1. Клонировать репозиторий и перейти в каталог проекта: 
    git clone https://github.com/GorshkovIoann/mesto.git
cd mesto
  2. Установить зависимости: 
    npm install
  3. Запустить дев-сервер (webpack-dev-server): 
    npm run dev

    Откройте адрес, который покажет сборщик (обычно http://localhost:8080).

  4. Альтернатива (быстрая проверка статических файлов): 
    # из папки src
python -m http.server 5500
# открыть http://localhost:5500

    Подходит если в проекте нет модулей уровня сборщика.

5. Сборка и деплой на GitHub Pages

Команды, описанные в package.json:

npm run build    # webpack --mode production -> создаёт dist/
npm run deploy   # gh-pages -d dist -> публикует dist/ в ветку gh-pages

Процедура:

  1. Установить зависимости: npm install.
  2. Собрать: npm run build.
  3. Опубликовать: npm run deploy. После выполнения содержимое dist/ будет отправлено в ветку gh-pages и доступно на GitHub Pages по адресу вида https://<ваш-логин>.github.io/<репозиторий>.
